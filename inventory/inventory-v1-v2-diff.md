# inventory v1·test와 v2 비교

`김지민/inventory/`에 있는 CSV 3개를 비교한 결과다. 2026-11-18 기준.

## 1. 파일 3개

| 파일 | 커밋 | 만든 방법 | 자산 수 |
|---|---|---|---|
| inventory-v1.csv | 9abcd8d | 팀 레포의 video-·image-·post- md 61개를 직접 읽고 자산을 뽑음 | 15 |
| test-inventory-v1.csv | 49e6ca6 | v1과 같은 방법으로 다시 만듦 | 15 |
| inventory-v2.csv | 6123eac | 팀원 inventory-v1.csv 5개를 합침 (자산 22개 중 근거수 순 15개) | 15 |

- `inventory-v1.csv`와 `test-inventory-v1.csv`는 내용이 한 글자도 다르지 않다(파일 해시 같음).
- 그래서 실제로 다른 내용은 **v1(=test)**과 **v2** 두 가지다.

## 2. 만드는 규칙의 차이

| 구분 | v1 / test | v2 |
|---|---|---|
| 재료 | md 파일 61개 | 팀 레포의 inventory-v1.csv 5개 (inventory/, 김민솔, 김주연, 김지민, 조정민) |
| 근거수 세는 법 | 한 파일에 자료가 여러 건이면 건마다 셈 | 파일 1개 = 1건 |
| 여러 건으로 센 파일 | 옛 전남도청 사진 11장 → 11건, ACC 설계개념 사진 5장 → 5건, ACC 웹진 사진 장소 6묶음 → 6건 | 없음 |
| 근거자료 | 내가 읽고 고른 파일 | 다섯 목록의 근거자료를 중복 없이 합침 |
| 이름이 다른 같은 자산 | 해당 없음 | 한 행으로 합침 (상권 쇠퇴 → 충장로 상권 변화, 구시청 → 구시청 사거리, 충장로우체국(우다방) → 충장로 우체국, 여덟번째파장 → 여덟 번째 파장) |
| 유형 | 내가 정함 | 목록끼리 다르면 다수결 (동명동 산업 3 : 커뮤니티 2 → 산업) |
| 설명 | 내가 씀 | 내 목록에 있으면 내 설명, 없으면 처음 나온 목록의 설명 |
| 동점 정리 | 근거 파일 수 → 표에 없던 유형 먼저 → 가나다순 | 가나다순 |
