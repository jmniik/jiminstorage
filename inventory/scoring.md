# 자산 평가 기준 (scoring)

`inventory` 자산 목록의 자산을 평가하는 우리 팀 기준이다. 2026-11-18 제안.
점수는 근거 자료(archive의 video-·image-·post- md)에서 확인할 수 있는 것만 보고 매긴다.

## 항목

| 항목 | 보는 것 |
|---|---|
| 상품화 가능성 | 굿즈·메뉴·상징처럼 상품으로 옮길 소재가 근거 자료에 나오는지 |
| 웰니스 연계성 | 쉬기·걷기·먹기 같은 몸과 마음을 쉬게 하는 경험이 근거 자료에 나오는지 |
| 체험 가능성 | 방문자가 직접 해 볼 수 있는 활동이 근거 자료에 나오는지 |
| 접근성 | 찾아가는 방법이 근거 자료에 나오는지 |

## 점수 기준

### 상품화 가능성

| 점수 | 기준 |
|---|---|
| 5점 | 근거 자료에 이미 파는 굿즈·시그니처 메뉴·기념품이나, 별명·마스코트·상징물이 이름과 함께 나온다. |
| 3점 | 눈에 띄는 모양·색 같은 외형 설명은 나오지만, 파는 상품이나 별명·상징물은 나오지 않는다. |
| 1점 | 상품으로 옮길 소재가 근거 자료에 없거나, 팀 규칙상 상품과 떼어 다루는 5·18 관련 자산이다. |

### 웰니스 연계성

| 점수 | 기준 |
|---|---|
| 5점 | 근거 자료 2건 이상에 쉬기·걷기·먹기·해질녘 풍경 중 하나를 직접 해 보는 장면이나 설명이 나온다. 팀 태그로는 `쉼`·`걷기`·`한끼`·`해질녘`이다. |
| 3점 | 근거 자료 1건에만 그런 장면이나 설명이 나온다. |
| 1점 | 장소 이름이나 위치만 나오고, 쉬기·걷기·먹기 경험은 나오지 않는다. |

### 체험 가능성

| 점수 | 기준 |
|---|---|
| 5점 | 근거 자료에 방문자가 직접 하는 활동(만들기·해설 관람·VR·피크닉 등)과 운영시간이나 예약 방법이 함께 나온다. |
| 3점 | 직접 하는 활동은 나오지만, 운영시간이나 예약 방법은 나오지 않는다. |
| 1점 | 보기만 하는 장소로 나오거나, 직접 하는 활동이 나오지 않는다. |

### 접근성

| 점수 | 기준 |
|---|---|
| 5점 | 근거 자료에 주소와 함께 가는 방법(가까운 역·주차장·걸어서 걸리는 시간)이 나온다. |
| 3점 | 주소나 위치만 나오고, 가는 방법은 나오지 않는다. |
| 1점 | 위치가 근거 자료에 나오지 않거나 `미확인`이다. |

- 운영시간·주차 같은 정보는 자료 기준일 당시 내용이다. 지금도 같은지는 `미확인`일 수 있다.

## 합계

합계 = 상품화 가능성 + 웰니스 연계성 + 체험 가능성 + 접근성 (가중치 없음, 최저 4점, 최고 20점)
