# inventory v1·v2 차이와 v3 만든 방법

팀 레포의 inventory v1과 v2를 비교하고, 두 파일의 좋은 점을 합쳐 v3를 만들었다. 2026-11-18 기준.

| 이름 | 파일 | 만든 사람·커밋 |
|---|---|---|
| v1 | 팀 레포 맨 위 `inventory/inventory-v1.csv` | 김주연, be121cf |
| v2 | `김지민/inventory/inventory-v2.csv` | 김지민, 6123eac |
| v3 | 팀 레포 맨 위 `inventory/inventory-v3.csv` | 김지민 (이번에 만듦) |

## 1. v1과 v2의 차이

### 만든 방법

| 구분 | v1 | v2 |
|---|---|---|
| 재료 | 팀 레포의 video-·image-·post- md 61개 | 팀원 inventory-v1.csv 5개 (v1 포함) |
| 누가 판단했나 | 한 사람이 같은 기준으로 | 다섯 목록의 판단을 합침 |
| 근거수 | 파일 1개 = 1건. 같은 사진은 1건 | 파일 1개 = 1건. 같은 사진이라도 파일 이름이 다르면 따로 셈 |
| 유형이 다를 때 | 해당 없음 | 다섯 목록끼리 다수결 |

### 좋은 점과 아쉬운 점

| 구분 | v1 | v2 |
|---|---|---|
| 좋은 점 | 한 사람이 같은 기준으로 만듦. 같은 사진을 1건으로 셈. 겹치는 자산이 없음. 추정 근거가 없음 | v1 근거를 다 담고 근거가 더 많음. 근거 8건·6건·4건짜리 자산 3개가 더 들어옴. 팀 주제 밖인 양림동(남구)이 빠짐 |
| 아쉬운 점 | 근거가 많은 금남로(8건)·탄흔(6건)이 없음. 팀 주제 밖인 양림동이 들어감 | 충장로를 15건으로 셈(같은 사진 중복). 5·18민주화운동과 전일빌딩 탄흔 245개의 내용이 겹침 |

## 2. v3를 만든 방법

v2를 바탕으로 하고, v2의 아쉬운 점 두 개를 v1 방식으로 고쳤다.

| 단계 | 한 일 | 가져온 쪽 |
|---|---|---|
| 1 | v2를 바탕으로 씀: 다섯 목록의 근거자료를 중복 없이 합치고 파일 1개 = 1건으로 셈 | v2 |
| 2 | 충장로를 15건에서 14건으로 고침. 같은 사진을 담은 `image-chungjangro-night-street.md`와 `image-chungjangro-night-street-1.md`를 1건으로 셈. 근거자료 칸에는 두 파일 이름을 그대로 둠 | v1 |
| 3 | 전일빌딩 탄흔 245개를 5·18민주화운동에 합침. 탄흔의 근거 파일 6개가 모두 5·18민주화운동 근거에 이미 있어서, 합쳐도 5·18민주화운동은 14건 그대로 | v1 (한 행만 둠) |
| 4 | 5·18민주화운동 설명을 "옛 전남도청 최후 항쟁과 전일빌딩245에 남은 탄흔 245개 같은 기록이 전시와 함께 나온다"로 바꿔 합친 내용이 보이게 함 | 새로 씀 |
| 5 | 탄흔이 빠져 빈 15위는 근거 3건 동점(빛의 숲·충장로 우체국·플라자브릿지) 중 가나다순으로 빛의 숲 | v2 규칙 |

v2에서 그대로 둔 것
- 금남로, ACC 도서관 (근거가 충분함)
- 동명동 유형은 산업 (다섯 목록 다수결 3 : 2)
- 동명동·여덟 번째 파장 근거의 `image-4.md(추정)` (김지민 요청으로 넣은 것)
