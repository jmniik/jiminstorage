# inventory v2와 v3 비교

`김지민/inventory/inventory-v2.csv`에서 두 가지를 고쳐 `inventory-v3.csv`를 만들었다. 2026-11-18 기준.

## 1. 왜 v3를 만들었나

v2와 팀 레포 맨 위 `inventory/inventory-v1.csv`(김주연, be121cf)를 비교해 보니, v2가 근거가 더 많아서 낫지만 아래 두 가지는 맨 위 v1이 더 맞았다.

| 문제 | v2 | 맨 위 v1 |
|---|---|---|
| 충장로 근거수 | 15. 같은 공공누리 사진(62845)을 담은 두 파일을 2건으로 셈 | 14. 같은 사진은 1건으로 셈 |
| 5·18민주화운동과 전일빌딩 탄흔 245개 | 두 행이 같이 있어 내용이 겹침 | 5·18민주화운동 한 행만 있음 |

## 2. 고친 것

| 항목 | v2 | v3 | 이유 |
|---|---|---|---|
| 충장로 근거수 | 15 | 14 | `image-chungjangro-night-street.md`와 `image-chungjangro-night-street-1.md`는 같은 사진(공공누리 62845)이라 1건으로 셈. 근거자료 칸에는 두 파일 이름을 그대로 둠 |
| 전일빌딩 탄흔 245개 | 10위 (6건) | 5·18민주화운동에 합침 | 탄흔의 근거 파일 6개가 모두 5·18민주화운동 근거에 이미 들어 있음. 그래서 합쳐도 5·18민주화운동 근거수는 14 그대로 |
| 5·18민주화운동 설명 | "헬기 사격 탄흔·시민군·최후 항쟁 같은 기록이 여러 장소 전시와 함께 나온다" | "옛 전남도청 최후 항쟁과 전일빌딩245에 남은 탄흔 245개 같은 기록이 전시와 함께 나온다" | 합친 탄흔 내용이 설명에 드러나게 바꿈 |
| 15위 | 여덟 번째 파장 | 빛의 숲 (새로 들어옴) | 탄흔 행이 빠져 한 자리가 비었음. 근거 3건 동점(빛의 숲·충장로 우체국·플라자브릿지) 중 가나다순으로 빛의 숲 |

나머지 규칙은 v2와 같다.
- 재료: 팀원 inventory-v1.csv 5개
- 근거수: 근거자료를 중복 없이 합쳐 파일 1개 = 1건
- 이름이 다른 같은 자산은 한 행으로 합침
- 유형은 목록끼리 다르면 다수결
- 동점은 가나다순

## 4. 같이 알아 둘 것

- 빛의 숲은 ACC 지상 정원이다. 김민솔 목록에 ACC와 따로 들어 있던 자산이라 v3에서도 따로 뒀다. ACC에 합치려면 15위가 다시 바뀐다.
- 김주연 `image-4.md(추정)` 메모는 v2처럼 동명동·여덟 번째 파장 근거에 남아 있다.
- 15위 밖 자산은 다음과 같다.
  - 충장로 우체국 3, 플라자브릿지 3
  - 양림동 2, 우규승 2, 충장축제 2, 파파샵 2
