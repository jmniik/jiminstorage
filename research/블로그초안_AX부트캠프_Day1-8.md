## Day 3 · 11/13 (금) — 저장 → 보내기 → 받기 + 출처 다시 보기

**오늘 수업**
- 퀴즈 6문제로 어제 내용 복습

- 팀원 파일 받기(Pull) + 서로 검토 + 작업 규칙 정하기
- 공식자료 · 공공데이터(CSV)로 새 주제 조사

같은 정보도 출처마다 날짜랑 내용이 다를 수 있어서, 출처 A·B를 같이 봐야 함.

## Day 5 · 11/17 (화) — 아카이빙: 자료 1건 = 파일 1개

**오늘 수업**
- 자료마다 9줄 (기관 · 이름 · URL · 기준일 · 열람일 · 수집자 · 종류 · 태그 · 저작권/광고)
- 공공누리(써도 되는 자료인지), 광고 글 걸러 내기
- 팀 태그 + 태그 집계

**내가 한 것**
- 영상 6 + 사진 6 + 글 5 = **17건**을 파일 1개씩 저장 + my-metadata.csv
- "무단 전재 · AI 학습 금지"라고 적힌 영상 1건은 저작권 때문에 뺌
- 리뷰 인사이트 정리 (옛 전남도청 · 전일빌딩245)
- 기획전 이름 **「충동」** = **충**장로 + **동**명동 + "갑자기 뭔가 하고 싶어지는 마음"
- 주제 태그 8개: #전시 #힐링 #피크닉 #산책 #카페 #맛집 #빵지순례 #역사

**배운 점**
그냥 모으면 끝이 아니라, 나중에 다시 찾아 쓸 수 있게 이름표(태그 · 저작권)를 붙여야 함.
【직접 쓰기: 느낀 점 1줄】

## Day 6 · 11/18 (수) — 인벤토리: 모으기에서 고르기로

**오늘 수업**
- 자료랑 자산 차이: 자료 1건 = 파일 1개 / 자산 1개 = 표 1줄
- AI 초안이 틀리는 곳 찾기 → 평가 기준 먼저 쓰기 → 점수 → 가중 합계 → Top 고르기

**내가 한 것**
- 자산 목록 v1 → v2로 고치고 내 담당 행 확인
- 평가 기준 4개, 각각 1 · 3 · 5점 (근거 0건 / 1건 / 2건 이상), 광고 글은 뺌

| 기준 | 가중치 |
|---|---|
| 웰니스 연계성 | ×3 |
| 상품화 가능성 | ×2 |
| 접근성 | ×2 |
| 체험 가능성 | ×1 |
| 최고 점수 | 40점 |

- 팀 최종 자산 13개 → 핵심 자산 TOP 5: ① ACC ② 동명동 ③ 전일빌딩245 ④ 충장로 ⑤ 하늘마당

**배운 점**
기준을 먼저 정하고 점수를 매겨야 덜 흔들림.
【직접 쓰기: 느낀 점 1줄】

## Day 7 · 11/19 (목) — 브랜드 성격 + 말투 + 세계관

**오늘 수업**
- 타겟 고객 → 성격 · 말투 → 브랜드 스킬 파일(AI가 읽는 규칙) → 세계관 → 캐릭터 시트
- 여기서 정한 말투는 12/22 데모데이까지 팀의 모든 글 · 그림 · 화면에 씀

**내가 한 것**
- 캐릭터 '충동이' 아이디어 3개 (그중 하나: 광주 사투리로 말 거는 동네 토박이)
- 타겟 고객 메모, 브랜드 스킬, 세계관 초안
- 내 세계관 **「충이와 동이, 다시 함께 빛나다」**가 팀 세계관이 됨
  - 불씨 형제 충이 · 동이, 방해꾼 먹구름, 불꽃 조각 5개 (걷고 · 먹고 · 보고 · 알고 · 눕고), 마지막 장소는 노을 질 때 하늘마당
- 캐릭터 요청문(my-character-prompt.md) 올림

**배운 점**
【직접 쓰기: 지어낸 설정은 (상상)으로 표시한 이유, 세계관 정할 때 느낀 점 등】

## Day 8 · 11/20 (금) — 기획전 상품 + 홈페이지 설계

**오늘 수업**
- 기획전 상품 구성 → 홈페이지 칸 나누기 → 홈페이지 시안 그림
- 화면 설계서 + 데이터 표 → 예시 5줄 채우기 → 이번 주 정리

**내가 한 것**
- 내 상품안 → 팀 상품 정리 (묶음 2개 · 상품 4개, 모두 팀이 직접 구성)
- 홈페이지를 위에서 아래로 **5칸**으로 나눔 (글은 말투 규칙 4개: 묻거나 외치기 · 장소 말하기 · 20자 이내 · 반말)
- 홈페이지 시안 그림 + 예시 데이터 표
- 세계관을 **「오늘의 충동: 빛 조각을 찾아서」**로 다시 바꿈 → 빛을 잃은 전구 캐릭터 + 빛 조각 5개

**배운 점**
직접 구성한 상품을 진짜 파는 상품처럼 쓰면 안 됨. 없는 데이터를 있는 것처럼 적지 않기.
【직접 쓰기: 느낀 점 1줄】
