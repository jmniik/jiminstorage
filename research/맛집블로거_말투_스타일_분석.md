## 2. 블로거별 상세

### 1) 라앤플 (팬 2.3만+)
- **말투**: 공손한 해요체 하나로 통일. "~었어요", "~더라고요"
- **구조**: 도입(누구랑, 왜) → 가게별 소제목 → 공간 → 메뉴 → 마무리 혜택 안내
- **특징**: 한 문장마다 줄바꿈. 감탄보다 사실 위주("간이 세지 않고 깔끔해서 어른들 입맛에도 잘 맞았어요")
- **키워드 반복**: '다낭맛집'을 본문에 여러 번 넣음 (검색 노출용)

### 2) 몽몽 (팬 1.3만+)
- **말투**: "~소개해드리려고 합니다", "~더라고요", "이웃분들에게 추천해보고자 합니다"
- **구조**: 제목 반복 → 인사 → **목차** → 1. 매장 정보 → 메뉴판 → 메뉴별 → 총평
- **특징**: 📍(주소·전화·영업시간·주차) / 📌(핵심 포인트, 1인 가격대) 블록이 정형화
- **줄바꿈**: 한 문장을 2~3줄로 끊어서 모바일 가독성 높임

### 3) 여행하는어린왕자 (팬 1만+)
- **말투**: "~더라고요", "~했어요", "~입니다" 섞음
- **구조**: 가게 이름 → ©사진/글 표기 → 사진 1장마다 설명 2~3줄
- **특징**: 벽 사진·장독 등 **믿음 가는 근거**를 묘사. 메뉴 가격을 원 단위로 다 적고, 팁("수육(소)이 100원이라 꼭 챙기세요") 제공
- **마무리**: 📞⏰✅ 정보 블록

### 4) 준또 (팬 9,532)
- **말투**: "~답니다", "~었네요", "~더라고요" — 부드럽고 서정적
- **구조**: 원고료 고지 → 개인 경험 도입 → 가게 정보 → 메뉴별 소제목
- **특징**: 오감 묘사가 길다 ("양념 국물을 머금은 무는 젓가락을 대면 부드럽게 갈라지더라고요")
- **마무리**: 클립(짧은 영상) 첨부

### 5) 커피사랑경화 (팬 9,449, 유일한 푸드 인플루언서)
- **말투**: "안녕하세요 커피사랑경화에요" 고정 인사, "~더라고요", "~했습니다"
- **구조**: [지역+카테고리 맛집] 제목 → 인사 → 긴 도입 문단 → **✅️ 3줄 요약** → 본문 → 요약 문단 + 해시태그 + 메뉴·가격 정리
- **특징**: 문단을 줄바꿈 없이 길게 씀. 끝에 글 전체를 한 문단으로 다시 요약

### 6) 뭉망뭉 (팬 9,039)
- **말투**: "안녕하세요 뭉망뭉입니다"로 시작, "오늘도 읽어주셔서 감사합니다 그럼 이만"으로 끝. 존댓말 중간에 "완전 베스트까지는 아님 ㅋㅋ" 같은 반말 섞음
- **구조**: 인사 → "오늘의 주인공" 소개 → 메뉴판 → 메뉴별 평가 → 인사
- **특징**: **솔직 평가**(별로인 메뉴도 말함), 과장 표현("입안에서 춤을 추는 맛", "킥입니다"), 느낌표 많음

### 7) 보라마녀 (팬 8,829)
- **말투**: "~는데요", "~습니다" — 차분한 설명체
- **구조**: 촬영일·저작권 고지 → 날씨·상황 도입 → 코스(맛집 → 카페 → 단풍) 순서
- **특징**: 한 곳이 아닌 **나들이 코스** 형식. 맛집 글이지만 여행 분위기 묘사가 큼
- **마무리**: "~서둘러 다녀와보세요" 권유형

### 8) 뭉치84 (팬 8,467)
- **말투**: "~했어요~", "안 갈 이유가 없다!!!", "참 쉽죠잉?", "~ㅎㅎ" — 친구한테 말하는 수다체
- **구조**: 영업시간·주변 가볼만한곳 표 → 1.위치 → 2.주문방법 → … 번호 소제목
- **특징**: 한 줄에 4~8글자 정도로 아주 짧게 끊음. 속마음("사실 조금 쫄았거든요~") 많이 넣음

### 9) 태블리 (팬 7,660)
- **말투**: **"~다" 평서체** ("명소다", "편리하다", "방문해 보시길 바란다")
- **구조**: 1. 주차 → 2. 시장 → 3. 먹거리 추천 — 번호 소제목
- **특징**: 감정 표현 적고 정보(주차, 장날, 1인 5,000원 상차림, 애견동반 규칙) 중심. 안내문·기사 느낌

### 10) 꼬마별 (팬 7,050)
- **말투**: "~다", "~듯한 ㅋㅋ", "상당 -", "아쉽" — 명사형·말줄임 종결, 메모 같은 반말
- **구조**: 가게 이름 → 메뉴 + 가격 → 1~2줄 평 — 반복
- **특징**: 가격을 "18.0"(=18,000원)처럼 줄여 씀. 문장 끝에 " -"나 " !"를 붙이는 습관. '내돈내산' 표기
