### 공통 패턴

| 패턴 | 10편 중 | 예 |
|---|---|---|
| 제목에 `[과정명] + Day/주차` | 9편 | `[K-뉴딜 아카데미] AX 부트캠프 - ...` |
| 날짜 단위로 나눔 (Day/주차) | 8편 | DAY 1 (11/11) |
| 맨 위에 한 줄 요약이나 오늘 할 일 | 5편 | "한 줄 요약", "오늘의 커리어 스터디는" |
| 끝에 회고 틀 (KPT·KEEP·정리 3줄) | 3편 | KEEP / Problem / Try |
| 솔직한 감정 (힘듦·긴장·웃김) | 6편 | "소심해서 눈물날 뻔 ㅜㅜ" |
| 고지 문구 (협찬·과정 일환) | 2편 | "본 게시물은 ... 과정의 일환입니다" |

### 따라 할 만한 점 4개
1. **Day마다 같은 틀**: 날짜 → 오늘 주제 한 줄 → 배운 것 → 내가 만든 것 → 느낀 점
2. **결과물을 숫자로**: 리뷰 274건, 자산 13개, 최고 40점처럼
3. **끝에 짧은 회고**: 정리 3줄이나 KPT
4. **팀 기획 공개 범위 조심**: achich1처럼 아직 공개 안 한 팀 기획은 줄여 쓰기

## 2. 내 말투 분석

- 근거: 이 대화에서 내가 직접 쓴 메시지 5개 + CLAUDE.md에 내가 정한 규칙
- ⚠️ 글이 짧은 요청문뿐이라 **블로그용 말투로는 근거가 적어**. 예전에 쓴 글(블로그·과제·카톡 등)이 있으면 더 정확하게 뽑을 수 있어.

| 특징 | 내가 쓴 예 | 블로그에 쓰면 |
|---|---|---|
| 반말 | "~해줘", "~돼" | 본문을 반말 평서체("~했다", "~함")로 |
| 짧고 바로 본론 | "템플릿 만들어줘" | 인사 짧게, 첫 줄에 주제 |
| `+`로 덧붙이기 | "블로그 말투+블로그 글 스타일", "+ 거기에 내 말투 분석도" | 소제목·요약에 `+` 쓰기 |
| "참고로"로 조건 붙이기 | "참고로 나는 ax부트캠프 리뷰 쓸거야" | 덧붙이는 정보는 "참고로"로 |
| 이유를 붙여 말함 | "하루하루에 대한 리뷰를 쓸거라서 ~ 있어야 돼" | "~라서 ~했다" 문장 |
| 문장부호·이모지 거의 없음 | 마침표·느낌표 거의 없음 | 이모지는 소제목에만 조금 |
| 숫자·표로 분명하게 (CLAUDE.md 규칙) | "조건과 결과는 숫자로", "비교할 때는 표" | 결과물은 숫자랑 표로 |
| 지어내지 않기 (CLAUDE.md 규칙) | "내가 적지 않은 개인정보나 경험은 만들어 넣지 않는다" | 감정·경험 칸은 내가 직접 쓰기 |

### 블로그용 내 말투 정리
- **본문**: 반말 평서체 ("~했다", "~함"), 한 문장 짧게
- **정보**: 숫자랑 표로
- **덧붙임**: `+`, "참고로"
- **감정**: 짧게 한 줄. 지어내지 않고 직접 쓰기
- **이모지**: 소제목에만, 많이 안 씀
