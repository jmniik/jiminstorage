### 공통 패턴

| 패턴 | 10편 중 | 예 |
|---|---|---|
| 제목에 `[과정명] + Day/주차` | 9편 | `[K-뉴딜 아카데미] AX 부트캠프 - ...` |
| 날짜 단위로 나눔 (Day/주차) | 8편 | DAY 1 (11/11) |
| 맨 위에 한 줄 요약이나 오늘 할 일 | 5편 | "한 줄 요약", "오늘의 커리어 스터디는" |
| 끝에 회고 틀 (KPT·KEEP·정리 3줄) | 3편 | KEEP / Problem / Try |
| 솔직한 감정 (힘듦·긴장·웃김) | 6편 | "소심해서 눈물날 뻔 ㅜㅜ" |
| 고지 문구 (협찬·과정 일환) | 2편 | "본 게시물은 ... 과정의 일환입니다" |

### 따라 할 만한 점 4개
1. **Day마다 같은 틀**: 날짜 → 오늘 주제 한 줄 → 배운 것 → 내가 만든 것 → 느낀 점
2. **결과물을 숫자로**: 리뷰 274건, 자산 13개, 최고 40점처럼
3. **끝에 짧은 회고**: 정리 3줄이나 KPT
4. **팀 기획 공개 범위 조심**: achich1처럼 아직 공개 안 한 팀 기획은 줄여 쓰기

## 2. 내 말투 분석

- 근거: Claude 세션 「Ego 영상 아카이브 저장」(2026-11-17~11-19)에서 내가 쓴 메시지 **129개** + 이 대화 메시지 5개 + CLAUDE.md
- 129개 중 **26개는 수업용으로 정해진 긴 요청문**(예: "Ego로 ~를 열어줘. ~ 맨 위 9줄은 README 아카이브 규칙대로…")이라 내 말투에서 뺌 → **내가 직접 쓴 103개**로 분석
- ⚠️ 전부 AI한테 쓴 요청·대답이라, 사람한테 쓰는 블로그 글과는 조금 다를 수 있음

### 자주 쓰는 말 (103개 중)

| 말 | 몇 개 | 내가 쓴 예 |
|---|---|---|

| "~잖아"로 근거 대기 | 2 | "엑스포가 잘 돼서 유명해지고 대전 대표 마스코트가 된거잖아" |

### 말투 특징

| 특징 | 내가 쓴 예 | 블로그에 쓰면 |
|---|---|---|
| 반말 해체 ("~해", "~했어", "~야") | "여기 pdf 다운받아서 줄게", "1개 골라서 … 충동이가 선택됐어" | 본문을 "~했어 / ~였어"로 |
| 생각 흐름대로 말함 (아 → 그러면 → ~거지?) | "아 그러면 원 저작물에는 … 너가 사진을 보고 518태그를 넣었다는거지? 그래서 추정이라고 하는거고" | 배운 점을 "아 그래서 ~구나" 식으로 |
| 이상하면 바로 물어봄 | "무단전재 금지하면 쓰면 안되지 않아?", "7번은 근거자료가 video인데?" | 헷갈렸던 점 → 알게 된 점 순서로 |
| 이유를 붙여 의견 말함 | "상품화가능성도 봐야해서 최대한 귀여운 캐릭터로 만들고 싶어" | "~라서 ~했어" |
| 예를 들어 설명 | "대전의 꿈돌이처럼" | 비슷한 예 하나 붙이기 |
| 조건을 번호·목록으로 정리 | "꼭 들어갈 것 / 한 줄 소개 / 성격 3개 …" | 결과물은 번호·표로 |
| `+`, "참고로"로 덧붙이기 | "전신 4방향+상반신+얼굴", "참고로 얼굴이 작아도 됨" | 덧붙이는 정보에 |
| 나만 쓰는 말 | "드가자" (17개) | 블로그엔 설명 붙여서 한 번만 |
| 빠르게 쳐서 띄어쓰기·오타 있음 | "추가많 ㅐ", "처처히" | 올리기 전에 맞춤법 검사 |

### 블로그용 내 말투 정리
- **본문**: 반말 해체 ("~했어", "~였어", "~거 같아"), 문장 짧게
- **흐름**: 한 것 → 헷갈린 점("근데 ~?") → 알게 된 점("아 그래서 ~")
- **정보**: 숫자랑 표로
- **덧붙임**: `+`, "참고로", "일단"
- **감정**: 짧게 (ㅇㅋ, ㅡㅡ 정도). 지어내지 않고 직접 쓰기
- **느낌표·이모지**: 거의 안 씀
