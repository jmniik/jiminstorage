# 맛집 글 템플릿 — 정석 정보형

- 바탕: [맛집블로거_말투_스타일_분석.md](맛집블로거_말투_스타일_분석.md)의 ① 정석 정보형 (몽몽, 여행하는어린왕자, 커피사랑경화)
- 말투: 해요체 하나로 쓰기 ("~더라고요", "~했어요", "~추천드려요")
- 줄바꿈: 한 문장을 2~3줄로 끊기 (모바일에서 읽기 편하게)
- 키워드: 제목에 넣은 `[지역] [메뉴] 맛집`을 본문에 **4~6번** 다시 넣기
- 쓰는 법: `[ ]` 안을 채우고, `> 예시`는 참고만 하고 지우기 (예시에 나오는 가게·가격은 가짜)

---

## 제목

```
[지역] [메뉴/카테고리] 맛집 [가게명] [핵심 포인트 1~2개]
```
> 예시: 성수 파스타 맛집 OO키친 데이트 코스 런치 세트

---

## 0. 고지 (해당될 때만)

```
본 포스팅은 [업체명]로부터 [제품/식사/원고료]를 지원받아 작성되었습니다.
```
또는 `내돈내산 후기`

---

## 1. 인사 + 도입 (3~5줄)

```
안녕하세요 [닉네임]이에요

오늘은 [지역] [메뉴] 맛집
[가게명]을 소개해드리려고 해요.

[간 이유 / 누구랑 / 언제] 다녀왔는데
[한 줄 첫인상]이더라고요.
```
> 예시:
> 안녕하세요 OO이에요
>
> 오늘은 성수 파스타 맛집
> OO키친을 소개해드리려고 해요.
>
> 주말 점심에 친구랑 다녀왔는데
> 생각보다 훨씬 만족스럽더라고요.

---

## 2. 목차

```
목차
1. 매장 정보
2. 메뉴판
3. [메뉴 1]
4. [메뉴 2]
5. 총평
```

---

## 3. 매장 정보

```
📍 주소 : [주소]
📍 전화번호 : [번호]
📍 영업시간 : [시작 ~ 끝]
     브레이크타임 [시간]
📍 휴무 : [요일]
📍 주차 : [가능 / 불가 / 주변 공영주차장]

📌 [가게 특징 1]
📌 [가게 특징 2]
📌 인당 가격대 [최소~최대]원
```
> 예시: 📌 [역 이름] [N]번 출구에서 걸어서 [N]분
> 📌 창가 자리는 예약하면 앉을 수 있어요

공간 설명 (2~3줄씩, 사진 1장마다):
```
[입구/인테리어/좌석] 모습이에요.
[느낀 점]이라 [누구]랑 오기 좋겠더라고요.
```

---

## 4. 메뉴판

```
[메뉴 1] [가격]원
[메뉴 2] [가격]원
[메뉴 3] [가격]원

저는 [고른 메뉴]를 주문했어요.
```
꿀팁이 있으면 한 줄:
```
[세트/추가 메뉴/할인] 있으니 꼭 챙기세요.
```

---

## 5. 메뉴별 후기 (메뉴마다 반복)

```
[메뉴 이름]

[생김새/양] 모습이에요.

한 입 먹어보니 [식감]하고
[맛]해서 [느낌]이더라고요.

[같이 먹으면 좋은 조합 / 추천 이유]
```
> 예시:
> 트러플 크림 파스타
>
> 면 위에 트러플 슬라이스가 넉넉하게 올라가 있어요.
>
> 한 입 먹어보니 면이 쫄깃하고
> 소스가 진해서 끝까지 질리지 않더라고요.

※ 아쉬운 점이 있으면 솔직하게 한 줄 넣기 (믿음 가는 글이 돼요)

---

## 6. 총평

```
✅ [좋았던 점 1]
✅ [좋았던 점 2]
✅ 방문 전 체크 : [휴무 / 웨이팅 / 솔드아웃 등]

[지역] [메뉴] 맛집 찾고 계신다면
[가게명] 한번 가보시길 추천드려요.

오늘도 읽어주셔서 감사합니다
```

---

## 7. 마무리 정보 블록 + 지도 + 태그

```
✅ 주문 메뉴 : [메뉴 가격, 메뉴 가격]
⏰ 영업시간 : [시간]
📞 전화번호 : [번호]

[네이버 지도 첨부]

#[지역]맛집 #[지역][메뉴] #[가게명] #[동네]맛집 #[상황]맛집
```

---

## 쓰기 전 체크리스트

| 항목 | 확인 |
|---|---|
| 제목에 `지역 + 메뉴 + 맛집` 있음 | ☐ |
| 본문에 제목 키워드 4~6번 | ☐ |
| 📍 매장 정보 다 채움 (주소·시간·휴무·주차) | ☐ |
| 메뉴 가격을 원 단위로 다 적음 | ☐ |
| 사진 1장마다 설명 2~3줄 | ☐ |
| 협찬이면 맨 위에 고지 | ☐ |
| ✅ 총평 3줄 | ☐ |
| 해시태그 5개 이상 | ☐ |
