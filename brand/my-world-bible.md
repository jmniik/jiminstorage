# 충동이 세계관 (my-world-bible)

충동이가 사는 곳과 이야기 배경을 정리한 문서다. 2026-11-19.
캐릭터 성격·말투는 팀 레포 `brand/persona.md`(1e5331b)를 따른다. 지어낸 설정은 (상상), 확인하지 못한 내용은 미확인으로 적었다.
리뷰 번호(#)는 `조정민/26.11.17/all-reviews.csv`의 번호다.

## 3. 갈등 — 자료에 실제로 나온 문제

| 문제 | 자료 내용 | 근거 파일 |
|---|---|---|
| 언제 열리는지 모른다 | 임시 개방(5/1~5), 정식 개방, "다시 열린" 같은 소식이 따로따로 나온다. 개방 기간은 미확인 | `all-reviews.csv` #31, #33, #35, #40 |
| 쓰레기 | ACC가 '쓰레기 되가져가기' 인증 이벤트를 열고, "쓰레기는 가져가고 잔디는 지키자"는 약속을 내걸었다 | `all-reviews.csv` #37, #40 |
| 몰랐던 이용 수칙 | 금연·금주·취사 금지 같은 수칙을 알고 가야 한다 | `all-reviews.csv` #33 · `김지민/brand/my-segments.md` |
| 겨울엔 볼거리가 적다 | "겨울이라 볼거리는 적지만…", 페르소나 A의 불편한 점 | `all-reviews.csv` #16 · `여행객_페르소나.pdf` 3쪽 |
| 건물 안은 붐빈다 | ACC 건물 안 리뷰 50건 중 '좁음·혼잡' 10건. 그래서 밖(하늘마당)으로 나와 쉰다 | `팀_통합_웰니스_스토리.pdf` 3쪽 |
| 주차비 | 주차는 편하지만 주차비가 비싸다 | `all-reviews.csv` #11 |
| 햇볕 | 피크닉 글 제목 "태양을 피하고 싶어". 본문이 없어 그늘이 부족하다는 뜻인지는 미확인 | `조정민/26.11.17/archive/post-skyyard-picnic-date.md` |

- 이야기에서는 충동이가 이 문제를 시민과 함께 푸는 쪽으로 쓴다 (상상). 예: 쓰레기를 되가져가며 잔디를 지키기, 겨울엔 실내 전시·도서관으로 옮겨 가기.
- 하늘마당은 옛 전남도청 바로 뒤 ACC 위에 있다. 5·18은 갈등 소재로 쓰지 않는다(팀 규칙: 사실만 소개, 캐릭터와 떼기).

## 4. 가치 — K-웰니스와 이어지는 것

| 가치 | 자료 내용 | 근거 파일 |
|---|---|---|
| 누구나, 자유롭게 쉬기 | "누구나 돗자리 하나 깔고 자유롭게 쉴 수 있는 소중한 공간", "앉아만 있어도 힐링" | `all-reviews.csv` #1, #33 |
| 몸을 내려놓기 | "양말 벗고 누우세요" | `all-reviews.csv` #2 · `팀_통합_웰니스_스토리.pdf` 3쪽 |
| 멈추는 것도 쉼 | 멍때리기 대회 "쉬는 것도 예술", 90분 동안 멈춰 호흡에 집중 | `all-reviews.csv` #29, #30 · `팀_통합_웰니스_스토리.pdf` 4·6쪽 |
| 자연과 계절 느끼기 | 꽃·잔디·노을로 계절을 온전히 느낌 | `all-reviews.csv` #7, #10, #12 |
| 함께 지키는 쉼터 | 쓰레기 되가져가기, 잔디 지키기 약속 | `all-reviews.csv` #37, #40 |

- 팀 자료에서 웰니스 근거가 가장 강한 장소가 하늘마당이다. 쉬기·마음·자연이 모두 '근거 여러 개'로 나온다(`팀_통합_웰니스_스토리.pdf` 4쪽).
- 기획전 부제 "여러 충동을 충동(충장로+동명동)에서"와 이어진다. 하늘마당은 그중 '눕고 싶은 충동'의 자리다(`readme.md` 주제 한 줄 요약).
