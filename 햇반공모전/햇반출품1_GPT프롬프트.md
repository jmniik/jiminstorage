# 햇반출품1 GPT 이미지 생성 프롬프트 (제품 앞·뒤·옆면)

- 작성일: 2026-11-13
- 대상: ChatGPT 이미지 생성
- 첨부할 파일 2개 (순서대로)
  1. `참고이미지/햇반로고.png` → **이미지 1** (로고)
  2. `참고이미지/햇반용기.png` → **이미지 2** (용기)
- 순서: **프롬프트 A**로 3면을 한 장에 뽑아 모양을 확정 → 마음에 들면 **프롬프트 B**로 각 면을 따로 크게 뽑기
- 증빙: 프롬프트와 생성 화면을 캡처해서 저장 (공모전 AI 제작 증빙용)

---

## 프롬프트 A: 3면도 한 장 (먼저 이걸로)

아래를 그대로 복사해서 이미지 2개와 함께 보내면 돼.

```
첨부한 이미지 2개를 참고해서 제품 콘셉트 이미지를 만들어줘.
- 이미지 1: 햇반 로고 (빨간 원 안에 '햇반' 글자)
- 이미지 2: 햇반 즉석밥 용기

[가장 중요한 규칙]
1. 이미지 2의 용기는 모양, 크기, 비율, 색, 질감을 절대 바꾸지 마. 위가 둥근 원형 테두리, 테두리의 작은 뜯는 탭, 아래쪽이 각진 다면체 그릇 모양을 그대로 유지해. 사각형으로 바꾸거나 더 깊게 만들지 마.
2. 이미지 1의 로고 모양도 바꾸지 마. 글자 모양을 새로 디자인하지 마.
3. 이미지 안에 설명 글자, 라벨, 화살표, 워터마크를 넣지 마.

[제품 설명]
용기 위의 필름은 떼어낸 상태이고, 그 위에 다회용 뚜껑을 얹은 모습이야.
- 뚜껑: 용기의 원형 테두리에 딱 맞는 원형 뚜껑. 낮고 완만한 돔 모양(돔 높이는 용기 높이의 절반 이하). 색은 햇반 필름 같은 무광 아이보리 #F0E2CF. 용기 테두리의 뜯는 탭은 뚜껑 밖으로 그대로 보이게.
- 플립 마개: 뚜껑 가운데에 작은 원형 마개(지름은 뚜껑의 약 1/4). 색은 햇반 로고 빨강 #C71C22, 실리콘 질감. 뒤쪽에 작은 경첩이 있어서 위로 젖혀 열리는 구조. 지금은 닫힌 상태.
- 로고 각인: 마개 윗면에 이미지 1의 로고 중 '햇반' 두 글자를 음영 각인으로 넣어줘. 흰색이나 다른 색을 쓰지 말고, 마개와 같은 빨간색 #C71C22 안에서 살짝 눌려 들어간 그림자와 빛만으로 글자가 보이게. 작은 문구와 ® 표시는 빼.
- 손잡이: 뚜껑 좌우 양쪽에 하나씩, 총 2개. 빨강 #C71C22 실리콘. 뚜껑 가장자리를 따라 납작하게 접혀 있는 상태.
- 클립: 각 손잡이 바로 아래에 작은 아이보리 클립이 용기 테두리를 물고 있음.

[구성]
같은 제품을 한 장에 세 방향으로 나란히 보여줘. 왼쪽부터:
1) 앞면: 정면 약간 위(약 20도)에서 본 모습, 손잡이 2개가 좌우 대칭으로 보이게
2) 옆면: 90도 옆에서 본 모습, 돔 높이와 손잡이 한쪽이 보이게
3) 뒷면: 뒤에서 약간 위에서 본 모습, 마개 경첩이 보이게
세 개 모두 같은 크기, 같은 카메라 높이, 같은 조명.

[스타일]
깔끔한 스튜디오 제품 사진. 따뜻한 아이보리 단색 배경, 부드러운 자연광, 바닥에 은은한 그림자. 실제 제품처럼 사실적으로. 가로 3:2 비율.
```

## 프롬프트 B: 각 면 따로 (A가 마음에 들면)

A 결과가 나온 같은 대화창에서 이어서 보내.

**B-1 앞면**
```
방금 만든 제품과 완전히 같은 모양, 같은 색, 같은 로고 각인으로 앞면 한 컷만 크게 만들어줘. 정면 약간 위(약 20도) 시점, 손잡이 2개 좌우 대칭. 따뜻한 아이보리 배경, 스튜디오 조명. 글자나 라벨은 넣지 마. 세로 4:5 비율.
```
**B-2 옆면**
```
같은 제품을 90도 옆에서 본 한 컷만 크게 만들어줘. 돔 높이와 손잡이 한쪽, 용기의 각진 아랫부분이 잘 보이게. 모양, 색, 각인은 그대로. 글자나 라벨은 넣지 마. 세로 4:5 비율.
```
**B-3 뒷면**
```
같은 제품을 뒤에서 약간 위에서 본 한 컷만 크게 만들어줘. 플립 마개의 경첩이 보이게. 모양, 색, 각인은 그대로. 글자나 라벨은 넣지 마. 세로 4:5 비율.
```
**B-4 윗면 (로고 각인 확인용, 선택)**
```
같은 제품을 바로 위에서 내려다본 한 컷 만들어줘. 원형 뚜껑과 가운데 빨간 마개, 마개 위의 '햇반' 음영 각인이 또렷하게 보이게. 좌우 손잡이 2개도 보이게. 글자나 라벨은 넣지 마. 1:1 비율.
```

## 결과가 이상하게 나올 때 붙일 수정 문장

| 문제 | 추가로 보낼 문장 |
|---|---|
| 용기가 사각형이나 반찬통이 됨 | `용기는 이미지 2와 똑같이 해줘. 위는 원형, 아래는 각진 그릇 모양. 새로 디자인하지 마.` |
| 로고가 흰 글씨로 나옴 | `로고는 흰색 말고, 빨간 마개와 같은 색으로 눌린 음영 각인만으로 보이게 해줘.` |
| 로고 글자가 깨짐 | `각인 글자는 이미지 1의 '햇반' 글자 모양을 그대로 따라 해줘. 다른 글자를 만들지 마.` |
| 손잡이가 1개거나 너무 큼 | `손잡이는 좌우에 정확히 2개, 작고 납작하게 접힌 상태로 해줘.` |
| 돔이 너무 높음 | `뚜껑 돔을 더 낮게 해줘. 용기 높이의 절반 이하로.` |
| 세 면의 모양이 서로 다름 | `세 이미지가 모두 같은 제품이어야 해. 모양, 크기, 색을 똑같이 맞춰줘.` |

## 참고

- 로고는 이번엔 **음영 각인(같은 빨강 안에서 눌린 그림자로만 보이게)**으로 바꿨어. 흰색을 안 쓰니까 이미지가 깔끔해져.
- 공식 로고를 출품작에 써도 되는지는 공모요강의 로고 사용 기준을 확인해야 해 (아직 미확인).
