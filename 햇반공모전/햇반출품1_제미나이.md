## ① P2 (3번 장: 찬장 컵밥)

```
실제 카메라로 찍은 상업 제품 사진을 만들어줘. 일러스트·3D 렌더·애니메이션 느낌 없이 사실적으로.

장면: 주방 찬장 한 칸을 실제 마트에서 파는 컵밥 10개 이상이 빽빽하게 채운 모습. 컵밥은 종이 컵 용기 + 투명 플라스틱 뚜껑, 옆면에 음식 사진이 들어간 띠지 디자인. 답답하고 꽉 찬 느낌.
규칙: 'No.1' 같은 순위 표기, % 숫자, 작은 글씨는 넣지 마. 메뉴 이름 정도의 큰 글자만 허용. 워터마크 없이.
구도: 세로 4:5. 위쪽 1/3은 흰 여백으로 비워줘(나중에 제목을 넣을 자리).
```

## ② P6 (8번 장: 4가지 맛 완성)

```
첨부한 이미지 1은 햇반 용기, 이미지 2는 우리 제품(햇뚜 뚜껑과 한알양념 포장)이야.

실제 음식 사진을 만들어줘. 일러스트나 애니메이션 느낌 없이, 실제 카메라로 찍은 푸드 사진처럼.
장면: 위에서 내려다본 2×2 구성. 뚜껑을 연 햇반 용기(이미지 1과 같은 모양) 4개에 각각 카레밥, 짜장밥, 고추장 비빔밥, 불고기 덮밥. 전자레인지에 데운 밥에 소스가 골고루 섞인 모습으로, 밥알이 촉촉하고 윤기 있게. 장난감처럼 동글동글한 밥알이나 과하게 선명한 색은 피해줘.
각 용기 오른쪽 아래에 해당 맛 한알양념 포장 1개. 포장은 이미지 2와 똑같이: 가장자리가 톱니 모양으로 접착된 반투명 컬러 비닐 안에 둥근 원반형 양념이 비쳐 보임(카레 노랑, 짜장 갈색, 고추장 빨강, 불고기 진갈색).
규칙: 흰 배경, 글자·라벨·워터마크 없이. 세로 4:5. 위쪽 1/3은 흰 여백으로 비워줘.
```

## ③ P7 (9번 장: 부피 비교)

```
첨부한 이미지 1은 햇반 용기, 이미지 2는 우리 제품(햇뚜 뚜껑과 한알양념 포장)이야.

실제 제품 사진처럼 사실적으로 만들어줘. 흰 배경, 부드러운 그림자.
위쪽: 실제 마트에서 파는 컵밥 6개(종이 컵 용기 + 투명 뚜껑, 음식 사진 띠지)를 2줄 3단으로 쌓고, 얇은 점선 상자로 감싸기. 'No.1'·% 숫자·작은 글씨 없이.
가운데: 아래 방향 화살표.
아래쪽: 햇반 6개 = 필름 붙은 햇반(이미지 1) 5개를 낮게 쌓은 것 + 이미지 2의 햇뚜를 씌운 햇반 1개. 그 옆에 한알양념 포장 6개. 포장은 이미지 2와 완전히 같게: 가장자리가 톱니 모양으로 접착된 반투명 컬러 비닐 안에 둥근 원반형 양념이 비쳐 보임(카레 노랑, 짜장 갈색, 고추장 빨강, 불고기 진갈색). 네모 큐브나 다른 포장 모양 금지.
햇뚜 모양은 이미지 2와 똑같이: 원형 아이보리 낮은 돔 뚜껑, 가운데 빨간 원형 플립 마개에 '햇반' 음영 각인, 좌우 빨간 손잡이 2개.
규칙: 아래쪽 전체가 위쪽 컵밥보다 확실히 작아 보이게. 글자·워터마크 없이. 세로 4:5. 위쪽 여백은 조금(약 15%)만.
```
