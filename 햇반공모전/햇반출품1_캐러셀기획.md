# 햇반출품1 캐러셀 기획: 햇뚜 + 한알양념 (12장)

- 작성일: 2026-11-13 (접수 마감 당일 23:59)
- 참고: aiarchive.zip '햇-반 취향껏 익혀밥' 캐러셀 16장 (사용자가 보낸 캡처로 확인)
- 형식: 4:5 세로 (1080×1350), 12장

## 0. 참고 게시물에서 가져올 것

| 요소 | 참고 게시물 | 우리 적용 |
|---|---|---|
| 흐름 | 공감 → 문제 → 제안 → 원리 → 반론 → "NO!" → 구매 구조 → 확장 → 사용법 요약 → 마무리 → 제작 과정 | 같은 흐름. 주제만 "취향"에서 **"부피 + 맛 선택"**으로 |
| 배경 | 구겨진 흰 종이 질감 | 똑같이 흰 종이 질감 |
| 고정 요소 | 왼쪽 위 햇반 로고 | 왼쪽 위 햇반 로고 (사용 가능 여부는 공모요강 확인) |
| 글자 | 검정 고딕, 굵게/얇게 섞기, **빨간 박스 강조** | 같은 방식, 빨강 #C71C22 |
| 대화 | 흰/빨강 말풍선 | 같은 방식 |
| 제작 과정 | 스케치 → 피그마 → AI 생성 | **컨펌 보드 → GPT 생성** (증빙도 겸함) |

## ⚠ 주의: 참고 게시물과 제품 모양이 많이 비슷함

참고 게시물도 **아이보리 원형 재사용 뚜껑 + 가운데 빨간 원형 '햇반' 버튼 + 기존 햇반에 계속 재사용** 구조야. 우리 햇뚜와 겉모습이 거의 같아서, 심사위원이 따라 했다고 볼 수 있어.

| 구분 | 참고 게시물 (익혀밥) | 우리 (햇뚜) |
|---|---|---|
| 핵심 기능 | 다이얼로 **식감** 선택 | 한알양념으로 **메뉴** 선택 + 흔들기 |
| 가운데 부품 | 돌리는 다이얼 | **젖히는 플립 마개** (큐브 넣는 입구) |
| 뚜껑 윗면 | 글자 띠, 설명문 인쇄 | **글자 없이 깔끔** (음영 각인만) |
| 손잡이 | 없음 | **좌우 빨간 손잡이 2개** |
| 같이 쓰는 것 | 없음 | **한알양념** (모든 제품 컷에 같이 등장) |

→ 이미지마다 **플립 마개가 열린 모습, 손잡이 2개, 한알양념**이 꼭 보이게 해서 차이를 눈으로 드러내기

## 1. 슬라이드 구성

종류: **T** = 글자만 (클로드 코드가 HTML로 제작), **P** = 제품 사진 (GPT로 생성) + 글자 (클로드 코드가 얹기)

| # | 종류 | 역할 | 큰 문구 | 작은 문구 / 내용 |
|---|---|---|---|---|
| 1 | P1 | 표지 | **흔들면, 오늘의 메뉴** | 햇뚜 + 한알양념 · 햇반 30주년 '갓 지은 AI디어' 공모전 출품작 · "컵밥, 자리 너무 차지하지 않나요?" |
| 2 | T | 공감 (말풍선) | 오늘 뭐 먹지? | 흰: "오늘 저녁 뭐 먹지?" / 빨강: "카레!" / 빨강: "난 짜장!" / 흰: "그럼 컵밥 종류별로 사 둘까?" |
| 3 | P2 | 문제 | 그런데 컵밥, **자리를 너무 차지해요** | 찬장을 꽉 채운 컵밥 사진 |
| 4 | T | 전환 | 밥은 이미 집에 있잖아요. **필요한 건 맛 한 알이니까** | (빨간 박스 강조) |
| 5 | P3 | 제안 | 그래서 제안합니다. **햇뚜 + 한알양념** | "집에 있는 햇반에 씌우는 다회용 뚜껑, 햇뚜. 맛별로 고르는 고형 양념, 한알양념." + 제품샷 |
| 6 | P4 | 원리 ① | 마개를 열고, **한 알 톡** | 손가락으로 빨간 플립 마개를 열고 한알양념을 넣는 클로즈업 |
| 7 | P5 | 원리 ② | 2분 데우고, **양손으로 흔들흔들** | "안 뜨거운 양쪽 손잡이로 잡고 흔들면 골고루 섞여요." + 흔드는 손 |
| 8 | P6 | 결과 | 한 알만 바꾸면, **메뉴가 바뀝니다** | 카레 · 짜장 · 비빔 · 불고기 덮밥 4컷 |
| 9 | P7 | 핵심 장점 | 부피는 줄이고, **맛은 그대로** | 위: 컵밥 6개 → 빨간 화살표 → 아래: 햇반 6개 + 햇뚜 + 한알양념 6개 |
| 10 | T | 반론 → 답 | 그런데, 잠깐… | 말풍선 "그냥 소스 부으면 되지 않나요?" "뚜껑을 또 사야 해요?" → 빨간 박스 **"뚜껑은 한 번, 양념만 바꾸면 끝"** + 3줄: 계량 끝 · 손 안 대고 흔들기 · 컵밥보다 작은 보관 부피 |
| 11 | P8 | 사용법 요약 | 요약하면, **햇뚜 이렇게 씁니다** | 아이콘 5단계 + 번호 목록: ① 필름 떼고 햇뚜 딸깍 ② 마개 열고 한알양념 톡 ③ 마개 반 열고 2분 ④ 꾹 닫고 양손으로 흔들기 ⑤ 씻어서 다음 햇반에 또 |
| 12 | T + 보드 | 마무리 + 제작 과정 | 오늘 저녁은, **흔들어서 정할게요** | 아래 절반: "제작 과정: ① 아이디어 정리 ② 구조 보드 제작 ③ GPT로 이미지 생성" + 컨펌 보드 축소 이미지 |

## 2. GPT 이미지 프롬프트 (P1~P8)

**공통 규칙** (첫 메시지로 먼저 보내고, 이미지 1 `참고이미지/햇반로고.png`, 이미지 2 `참고이미지/햇반용기.png` 첨부)

```
지금부터 인스타 캐러셀용 제품 사진을 한 장씩 만들 거야. 모든 사진에 아래 규칙을 똑같이 적용해줘.

[제품: 햇뚜]
- 아래 용기는 이미지 2의 햇반 용기 그대로 (위는 원형, 아래는 각진 그릇 모양). 필름은 떼어낸 상태.
- 뚜껑: 원형, 낮은 돔, 무광 아이보리 #F0E2CF. 윗면에 글자나 인쇄 없음.
- 가운데: 빨강 #C71C22 원형 실리콘 플립 마개. 뒤쪽 경첩으로 위로 젖혀 열림. 윗면에 이미지 1의 '햇반' 글자를 같은 빨강으로 음영 각인 (흰색 없음).
- 좌우: 빨강 #C71C22 실리콘 손잡이 2개, 각 손잡이 아래 작은 아이보리 클립.
[한알양념]
- 지름 3cm 정도 둥근 고형 양념. 맛별 작은 개별 포장 (카레 노랑, 짜장 갈색, 고추장 빨강, 불고기 진갈색).
[스타일]
- 깔끔한 스튜디오 제품 사진, 밝은 흰색~아이보리 배경, 부드러운 자연광. 세로 4:5.
- 이미지 안에 글자, 라벨, 로고(마개 각인 제외), 워터마크 넣지 마. 글자는 내가 나중에 넣을 거야.
- 위쪽 1/3은 글자 넣을 여백으로 비워줘. (왼쪽 위에는 햇반 30주년 로고가 들어갈 자리)
- 플립 마개가 열린 컷에는 항상 한알양념이 마개 구멍 안으로 들어가는 모습을 같이 넣어줘.
```

| P4 원리① | `P4: 클로즈업. 한 손가락으로 빨간 플립 마개를 젖혀 연 상태에서, 다른 손이 포장을 뜯은 한알양념(고추장 빨강)을 마개 구멍에 넣는 순간.` |

## 3. 진행 순서

1. GPT로 P1~P8 생성 → `출품1_이미지/P1.png` ~ `P8.png`로 저장
2. 클로드 코드가 공통 템플릿(종이 배경, 로고, 글꼴)으로 12장 HTML 제작 → P 이미지 끼우고 문구 얹기 → PNG 12장 출력
3. 글자만 들어가는 슬라이드(T: 2, 4, 10, 12)는 이미지 없이 지금 바로 제작 가능
