# 웰니스기획전 주제 태그 8개

예시 사이트의 충동 테마 5개에서 태그를 1~2개씩 뽑아 8개로 정리함.

## 최종 태그

#전시 #힐링 #피크닉 #산책 #카페 #맛집 #빵지순례 #역사

## 테마별 태그

| 충동 테마 | 장소·프로그램 | 태그 |
|---|---|---|
| 보고 싶은 충동 | ACC 무료 전시, 마음힐링교육 | #전시 #힐링 |
| 눕고 싶은 충동 | 하늘마당 잔디언덕, 돗자리 | #피크닉 |
| 걷고 싶은 충동 | 동명동 카페골목, 푸른길 | #산책 #카페 |
| 먹고 싶은 충동 | 충장로·구시청 저녁 한 끼, 공룡알빵 | #맛집 #빵지순례 |
| 알고 싶은 충동 | 옛 도청·전일빌딩 (5·18) | #역사 |

- 개수: 2 + 1 + 2 + 2 + 1 = 8개
- "알고 싶은 충동"은 impulse 페이지에만 있음 (goods 페이지는 테마 4개)
