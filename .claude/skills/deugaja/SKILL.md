# 드가자: 팀 레포 원하는 위치로 올리기

1. 사용자가 말한 이름으로 llm-local 안의 파일이나 폴더를 찾는다.
   - 경로를 그대로 말했으면 그대로 쓴다.
   - 파일 이름만 말했으면 llm-local 안에서 검색한다 (.git, .claude는 빼고).
   - 하나도 없거나 여러 개가 걸리면 올리지 말고 후보를 보여주고 물어본다.
   - 여러 개를 한 번에 말했으면 다 같이 올린다.
2. 올릴 위치(팀 레포 안 폴더)를 정한다.
   - 사용자가 위치를 말했으면 그대로 쓴다 (예: `김지민/archive`, `조정민/26.11.18`, 팀 레포 맨 위는 `.`).
   - 위치를 말하지 않았으면 올리지 말고 "어디로 드가?"라고 먼저 묻는다. 예전처럼 `김지민/llm-local/`로 마음대로 넣지 않는다.
   - 파일은 `<위치>/<파일 이름>`으로 들어간다 (llm-local 안의 폴더 경로는 따라가지 않는다).
3. 올릴 파일을 열어서 비밀번호, API Key, 토큰, 개인정보가 있는지 확인한다. 있으면 멈추고 알려준다.
4. 먼저 미리보기로 돌린다 (경로는 llm-local 기준):
   ```bash
   bash .claude/team-upload.sh --dry-run --to "<위치>" "<경로1>" "<경로2>"
   ```
   - `OVERWRITE`가 나오면 팀 레포의 그 파일을 덮어쓰게 된다. 특히 다른 팀원 폴더면 올리지 말고 사용자에게 먼저 물어본다.
   - `NEW FOLDER`가 나오면 새 폴더가 생긴다고 같이 알려준다(이상한 위치면 물어본다).
5. 문제가 없으면 실제로 올린다:
   ```bash
   bash .claude/team-upload.sh --to "<위치>" "<경로1>" "<경로2>"
   ```
6. 결과를 반말로 짧게 알려준다. 무엇이 어디로 올라갔는지, 커밋 번호를 표로 적는다.
   - `NO CHANGE`가 나오면 팀 레포에 이미 같은 내용이 있다고 알려준다.
   - `ERROR`가 나오거나 push가 실패하면 메시지를 그대로 알려준다.
