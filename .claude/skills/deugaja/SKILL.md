# 드가자: 팀 레포 김지민 폴더로 올리기

1. 사용자가 말한 이름으로 llm-local 안의 파일이나 폴더를 찾는다.
   - 경로를 그대로 말했으면 그대로 쓴다.
   - 파일 이름만 말했으면 llm-local 안에서 검색한다 (.git, .claude는 빼고).
   - 하나도 없거나 여러 개가 걸리면 올리지 말고 후보를 보여주고 물어본다.
   - 여러 개를 한 번에 말했으면 다 같이 올린다.
2. 올릴 파일을 열어서 비밀번호, API Key, 토큰, 개인정보가 있는지 확인한다. 있으면 멈추고 알려준다.
3. 실행한다 (경로는 llm-local 기준):
   ```bash
   bash .claude/team-upload.sh "<경로1>" "<경로2>"
   ```
4. 결과를 반말로 짧게 알려준다. 무엇이 어디로 올라갔는지, 커밋 번호를 표로 적는다.
   - `NO CHANGE`가 나오면 팀 레포에 이미 같은 내용이 있다고 알려준다.
   - `ERROR`가 나오거나 push가 실패하면 메시지를 그대로 알려준다.
